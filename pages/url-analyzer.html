URL component decomposition
Component Parsed Value Risk Significance

Subdomain — (Awaiting input) Attackers often place legitimate brand names in subdomains (e.g., bank.com.scam-site.org).
Registered Domain — (Awaiting input) The actual paid domain identity that controls the website and DNS records.
Top-Level Domain (TLD) — (Awaiting input) Certain generic TLDs (.xyz, .top, .cam, .click) are statistically overrepresented in disposable phishing campaigns.
Port Number — (Standard 80 / 443) Non-standard port numbers (e.g., :8080, :4443) may indicate rogue server configurations or compromised hosts.
Path & Directory — (Awaiting input) Simulated paths like /auth/login.php designed to mimic legitimate portal endpoints.
Query Parameters — (Awaiting input) Tracking tokens or redirect instructions (e.g., ?redirect=http://malicious.com).
